# 🚗 Car Price Prediction using Machine Learning

A machine learning project that predicts used car selling prices based on vehicle specifications such as year, engine size, fuel type, transmission, mileage, and maximum power.

### Model Performance
✅ R² Score: 0.836

### Dataset
- 8,128 vehicle records
- 13 features
- Data cleaning & preprocessing
- Feature engineering
- Linear Regression & Polynomial Regression
