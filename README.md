# 🚗 Car Price Prediction

A machine learning project that predicts car prices based on various vehicle features such as engine capacity, torque, max_power, year, mileage, fuel type, transmission, km_driven, seller_type, owner, seats, and seller_type.

## 📌 Project Overview

The objective of this project is to build a predictive model that estimates the market price of a car using historical car sales data. This can help buyers, sellers, and dealerships make informed pricing decisions.

## 📂 Dataset

The dataset contains information about vehicles, including:

- Name: Identifies the car model and variant.
- Year: Indicates the manufacturing year of the vehicle.
- KM Driven: Represents the total distance traveled by the car in kilometers.
- Fuel: Specifies the type of fuel used, such as Petrol, Diesel, CNG, or Electric.
- Seller Type: Indicates whether the seller is an individual owner or a dealer.
- Transmission: Describes the gearbox type, either Manual or Automatic.
- Owner: Shows the number or type of previous owners of the vehicle.
- Mileage: Represents the vehicle’s fuel efficiency.
- Engine: Indicates the engine capacity, typically measured in CC.
- Max Power: Represents the maximum power output produced by the engine.
- Torque: Measures the rotational force generated by the engine.
- Seats: Indicates the seating capacity of the vehicle.

Target Variable
Selling Price: The market price of the vehicle to be predicted by the machine learning model.
